# Independent sets

Prove alpha(G) >= c*n^2/(2*m+n) for every finite simple graph with n >= 1 vertices and m edges. Maximize the exact rational c; the starting score is 1/2 and the optimum is 1.

Read rules.md. Edit only submission/ for a candidate: put one exact scored claim in submission.json and its complete proof in proof.md. Partial results are not accepted. Run `llm-verifier check --root .` for structural validation. The configured LLM judge reviews the proof; a person confirms official results. Local checks do not establish mathematical acceptance.
